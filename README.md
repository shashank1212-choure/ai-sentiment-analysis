# AI Sentiment Analysis

## Project Description
AI Sentiment Analysis is a Machine Learning based application that analyzes
a product review and predicts its sentiment.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript

## Machine Learning
- TF-IDF Vectorizer
- Logistic Regression

## Project Workflow

User enters review
        ↓
Frontend (HTML/CSS/JavaScript)
        ↓
Flask Backend
        ↓
TF-IDF Vectorizer
        ↓
Logistic Regression Model
        ↓
Sentiment Prediction
        ↓
Result displayed on website

## How to Run

Run the Flask backend:

python app.py

Then open index.html in a browser.

## Output
The application predicts the sentiment of the given review.
